FIRST MENSIVE WEBSITE
=====================

FILES
- index.html
- style.css
- script.js
- assets/love-wave-to-earth.mp3 (optional audio file; add your own permitted copy)

PREVIEW
Open index.html in a browser, or use VS Code Live Server.

MUSIC
Place an audio file you are allowed to use at:
assets/love-wave-to-earth.mp3

The player seeks to 03:39 and stops at 05:05. The project does not include the copyrighted song.

QR CODE / PUBLISHING
The QR code must point to a public website URL to work on another person's phone.
A local file or localhost address is not publicly accessible.

Easy publishing option:
1. Open https://app.netlify.com/drop
2. Sign in or create a Netlify account.
3. Drag and drop the whole project folder (first-mensive) or a ZIP containing its files.
4. Netlify gives you a public website URL.
5. Open that public URL. The QR code on the page will automatically point to it.
6. Share or save the QR code.

Keep index.html, style.css, script.js, and the assets folder together.
